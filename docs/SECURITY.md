# Segurança

O projeto é pessoal e local até a Fase 5. Até que autenticação, HTTPS e endurecimento
sejam implementados explicitamente, nenhum serviço deve ser publicado publicamente.

Segredos, tokens, cookies, senha, currículos integrais e anexos não são commitados.
Logs não devem conter payload pessoal integral. Links inseridos pelo usuário não são
buscados automaticamente nesta versão.
